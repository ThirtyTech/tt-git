## Focusing a pane

Keys go to the focused pane, the one with the green border. These keys work
from any pane:

| Key | Focuses |
|---|---|
| <kbd>1</kbd> | Graph |
| <kbd>2</kbd> | Status |
| <kbd>3</kbd> | Branches |
| <kbd>4</kbd> | Details (opening it if it's hidden) |
| <kbd>tab</kbd> / <kbd>shift+tab</kbd> | The next / previous pane |
| <kbd>ctrl+h</kbd> <kbd>ctrl+j</kbd> <kbd>ctrl+k</kbd> <kbd>ctrl+l</kbd> | The pane to the left / below / above / right |

Focusing status or branches while details covers them closes details and
brings them back.

## Moving the selection

Every list moves the same way:

| Key | Moves |
|---|---|
| <kbd>j</kbd> / <kbd>↓</kbd> | Down one row |
| <kbd>k</kbd> / <kbd>↑</kbd> | Up one row |
| <kbd>ctrl+d</kbd> / <kbd>ctrl+u</kbd> | Down / up a page |
| <kbd>g</kbd> / <kbd>G</kbd> | To the top / bottom |

As you move in the graph or the branch list, the details pane (when it's
open) follows the selection. It only loads the row you stop on, so holding
<kbd>j</kbd> through a long history stays fast.

## Zoom

<kbd>+</kbd> makes a pane fill the screen, and <kbd>+</kbd> again puts it
back. It zooms details if details is focused, and the graph otherwise.

<Screenshot name="graph-zoom" alt="The graph zoomed to fill the screen with details open below it" />

With the graph zoomed, <kbd>space</kbd> opens details below it at full width.

## The mouse

The mouse is on by default:

- Click a pane to focus it, or a row to select it.
- Double-click a row to do what <kbd>enter</kbd> does on it: a commit in the
  graph opens fullscreen with its changed files beside the diff, a file in
  Status opens its staging view and a folder folds or unfolds, a branch or
  tag is checked out, a stash is shown, a worktree opens, and a line in blame
  opens its commit.
- Click a tab's name in the branches pane's title (**Branches**, **Tags**,
  **Stash**, **Worktrees** and so on) to switch to it.
- Click a file in the details pane's [changed-files view](/panes/details/#changed-files)
  to show its diff.
- Click a row in the [staging view](/panes/staging/) to pick its hunk, or in
  line mode its changed line.
- Click an author or file in [Filter graph](/panes/graph/#filtering-by-author-or-file)
  to filter by it; a click outside the popup closes it.
- Scroll the wheel to scroll the pane under the pointer, focused or not. Over
  the diff in the changed-files view, the wheel scrolls the diff.
- <kbd>ctrl</kbd>+click a link in the details pane to open it with a plugin
  (see [Links](/panes/details/#links)).

In the [desktop app](/desktop/using/#the-mouse) you can also right-click a row
for a menu of its commands, and drag the borders between panes to resize them.

Set `mouse = false` in your [configuration file](/configuration/) to turn it
off, for example so your terminal's own text selection works without
holding <kbd>shift</kbd>.

## Getting help

<Screenshot name="help" alt="The Keybindings popup listing the graph pane keys" />

<Screenshot name="help-search" alt="The Keybindings popup narrowed by typing merge" />

Press <kbd>?</kbd> to see the keys for the focused pane, followed by the ones
that work everywhere. Start typing to narrow the list: `stash` finds every
stash key, `ctrl` every control key. <kbd>backspace</kbd> deletes a character,
<kbd>ctrl+u</kbd> clears what you typed, and <kbd>esc</kbd> closes the popup
(so does <kbd>?</kbd> while nothing is typed).

The popup lists the keys as they're bound now, so it includes any you've
changed in your config. Its top right corner shows the version of tt-git
you're running, like **tt-git 0.3.0**. *About* in the palette shows it too,
with the developer and where the source is; see
[About tt-git](/git/palette/#about-tt-git).

<Aside type="tip">
	To run a command without remembering its key, press <kbd>:</kbd> or
	<kbd>ctrl+p</kbd> for the [command palette](/git/palette/).
</Aside>

To quit, press <kbd>q</kbd> or <kbd>ctrl+c</kbd>.

The full list of keys is in [Keyboard shortcuts](/reference/keys/).
