## What it does

<CardGrid>
	<Card title="A commit graph as the main view" icon="seti:git">
		Every branch, remote and tag in one `git log --all` graph with stable,
		colored lanes. Branches run straight down instead of shifting sideways.
		Filter it to one author or one file or folder.
	</Card>
	<Card title="Stage by file, hunk or line" icon="pencil">
		Stage, unstage, discard, commit, amend and stash from the status pane.
		Open a file to stage its changes a hunk or a single line at a time.
	</Card>
	<Card title="One list for all branches" icon="list-format">
		Local and remote branches share a row, sorted by when you last touched
		them. A status column tells you what's been pushed, what's behind and
		what's gone upstream.
	</Card>
	<Card title="Merged, unmerged, tags and stashes" icon="approve-check">
		See which branches are merged into your main branch, how far each
		release tag is from it, and every stash, each on its own tab.
	</Card>
	<Card title="Plugins built like herdr's" icon="puzzle">
		Plugins are plain programs with a TOML manifest. They add actions, react
		to events, open terminal panes inside tt-git and talk back through the
		CLI or a JSON socket.
	</Card>
	<Card title="In a terminal or a window" icon="laptop">
		The same app runs as a [desktop app](/desktop/) on Windows, macOS and
		Linux, drawn on the GPU with GPUI, the UI framework behind the Zed
		editor. Same panes, keys, config and plugins, plus menus and the mouse.
	</Card>
	<Card title="Light enough to leave open" icon="rocket">
		It redraws only when something changes and runs no git processes at
		idle. With a 28,000-commit repository open, it uses about 30 MiB.
	</Card>
</CardGrid>
